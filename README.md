AI and data engineer in Lagos, Nigeria (UTC+1). I build LLM pipelines and the Python data work underneath them: classification and extraction with model evals, and location data at the scale of millions of rows on a single laptop.

**Things here**

- [llm-article-gate](https://github.com/Biodun-ml/llm-article-gate): decides which travel articles are bookable, extracts grounded places and activities, and compares models on a labelled set. Ollama by default, Anthropic and OpenAI optional, Langfuse tracing.
- [geonames-importance](https://github.com/Biodun-ml/geonames-importance): ranks all 13.5M GeoNames places by importance in under 700 MB of memory, with overrides for the cases the data gets wrong.
- [gtfs-terminals](https://github.com/Biodun-ml/gtfs-terminals): finds terminals in GTFS feeds and links millions of places to the nearest one with a chunked KD-tree.
- [wikidata-change-watch](https://github.com/Biodun-ml/wikidata-change-watch): watches Wikidata-linked places for edits that matter, reviewed by rules first, then a local model, then a cloud model.
